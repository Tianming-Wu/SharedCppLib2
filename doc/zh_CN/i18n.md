# i18n - 国际化翻译模块

+ 名称: i18n
+ 命名空间: (无)
+ 文档版本: `1.0.0`

## CMake 配置信息

| 项目 | 值 |
|---------|---------|
| 命名空间 | `SharedCppLib2` |
| 库名称 | `i18n` |

包含方式:
```cmake
find_package(SharedCppLib2 REQUIRED)
target_link_libraries(target SharedCppLib2::i18n)
```

```cpp
#include <SharedCppLib2/i18n.hpp>
```

## 描述

`i18n` 提供基于 JSON 的翻译加载，支持 ID 键值查找。支持简单键→字符串映射、数组值索引访问，以及带 `${0}`、`${1}` 占位符的模板字符串替换。

未找到翻译时返回键本身——因此开发期间可以直接用英文文本作为键安全使用。

> [!TIP]
> 推荐的键格式为 `分类.模块.键名`（三级），如 `menu.file.open`、`ui.toolbar.save`、`dialog.confirm.title`。

## 语言文件结构

翻译文件为 JSON 格式，放置在可执行文件所在目录的 `lang/` 子目录下：

```
your_app/
├── yourapp.exe
└── lang/
    ├── en-US.json
    ├── zh-CN.json
    └── ja-JP.json
```

文件命名遵循 `语言-地区` 格式（如 `en-US`、`zh-CN`），与 `system_locale()` 返回的本地化代码一致。

### JSON 格式

每个文件是一个 JSON 对象，将键映射为值。支持两种风格：

**扁平风格**（简单项目）：

```json
{
    "menu.file.open": "打开",
    "menu.file.save": "保存",
    "dialog.confirm.title": "确认"
}
```

**嵌套风格**（推荐用于较大项目）：

```json
{
    "menu": {
        "file": {
            "open": "打开",
            "save": "保存"
        }
    },
    "dialog": {
        "confirm": {
            "title": "确认",
            "message": "确定要删除 \"${0}\" 吗？"
        }
    },
    "app": {
        "greeting": "你好，${0}！你有 ${1} 条新消息。"
    },
    "ui": {
        "status": {
            "connected": ["未连接", "连接中...", "已连接"]
        }
    }
}
```

嵌套对象在内部以 `:` 为分隔符展开——`"menu":{"file":{"open":"打开"}}` 变为键 `"menu:file:open"`。扁平与嵌套风格可在同一文件中混用。

- **字符串值** — 通过 `tr()` 进行简单键→文本查找
- **数组值** — 通过 `trl(key, index)` 访问，适用于状态显示
- **模板字符串** — `${0}`、`${1}` 等将被 `trx()` 中的参数替换

## 快速开始

```cpp
#include <SharedCppLib2/i18n.hpp>

int main() {
    i18n t;                           // 创建翻译器（生命周期必须长于使用）
    t.autoLoad();                     // 加载匹配系统区域的翻译，或回退到 en-US

    // 简单翻译 — xstring 输入，xstring 输出，类型保留
    auto text = i18n::tr(scl2::xstring("menu.file.open"));  // ansi → ansi

    // 数组索引
    auto status = i18n::trl(scl2::xstring("ui.status.connected"), 2);

    // 模板替换
    auto msg = i18n::trx(scl2::xstring("app.greeting"), {L"小明", 5});
    // "你好，小明！你有 5 条新消息。"
}
```

## 函数参考

### tr

```cpp
static scl2::xstring tr(const scl2::xstring& key);
```

返回 `key` 对应的翻译。返回类型与输入键的类型一致。未找到则返回 `key` 本身。

### trl

```cpp
static scl2::xstring trl(const scl2::xstring& key, size_t index);
```

从数组翻译中返回索引 `index` 处的值。返回类型与输入键的类型一致。缺失或越界时回退到 `key`。

### trx

```cpp
static std::wstring trx(const std::wstring& key_temp,
                        std::initializer_list<trx_arg> args);
```

翻译 `key_temp`，然后将占位符替换为传入的参数。

**占位符语法：**

| 占位符 | 行为 |
|--------|------|
| `${0}`, `${1}`, ... | 替换为对应索引的参数 |
| `${...}` | 替换为所有参数，以 `, ` 连接 |

参数可为：
- `const wchar_t*` / `const char*` / `scl2::xstring`
- `int`、`long`、`long long`、`unsigned`、`unsigned long long`
- `double`

**示例：**
```cpp
// JSON: "dialog.delete": "确认删除 \"${0}\" 吗？"
auto msg = i18n::trx(L"dialog.delete", {L"config.ini"});
// "确认删除 \"config.ini\" 吗？"

// JSON: "app.greeting": "你好，${0}！你有 ${1} 条消息。"
auto greeting = i18n::trx(L"app.greeting", {L"小明", 5});
// "你好，小明！你有 5 条消息。"

// JSON: "ui.list": "已选择: ${...}"
auto list = i18n::trx(L"ui.list", {L"A", L"B", L"C"});
// "已选择: A, B, C"

// nullptr 作为占位符 — ${N} 变空，${...} 可见空隙
auto partial = i18n::trx(L"app.greeting", {nullptr, 5});
// "你好，！你有 5 条消息。"

auto list_gap = i18n::trx(L"ui.list", {L"A", nullptr, L"C"});
// "已选择: A, , C"
```

> [!NOTE]
> 如果传入的参数数量少于模板中最高的 `${N}` 索引，未匹配的占位符将保持原样（不会被替换为空字符串）。使用 `nullptr` 可显式填充某个位置——对应 `${N}` 替换为空，在 `${...}` 中空隙在分隔符之间可见。

### trxl

```cpp
static std::wstring trxl(const std::wstring& key_temp, size_t index,
                         std::initializer_list<trx_arg> args);
```

结合数组索引访问与模板替换。

### system_locale

```cpp
static std::wstring system_locale();
```

以 `语言-地区` 格式返回系统区域设置（如 `"en-US"`、`"zh-CN"`）。仅 Windows 支持；其他平台返回空字符串。

### autoLoad / load

```cpp
void autoLoad();
bool load(const std::wstring& lang_code);
```

`autoLoad()` 检测系统区域并调用 `load()`。检测失败时默认使用 `"en-US"`。

`load()` 加载 `lang/{code}.json`。文件不存在时返回 `false`，成功返回 `true`。

### valid

```cpp
bool valid() const;
```

成功加载翻译文件后返回 `true`。

## 键命名规范

两种等效风格：

**扁平键** — 使用 `.` 作为分隔符：
```
分类.模块.键名
```

**嵌套键** — 使用嵌套 JSON 对象（内部以 `:` 展开）：
```
分类:模块:键名
```

| 层级 | 用途 | 示例 |
|------|------|------|
| 分类 | 界面区域或功能组 | `menu`、`dialog`、`ui`、`error` |
| 模块 | 具体组件 | `file`、`edit`、`confirm`、`status` |
| 键名 | 单个字符串 | `open`、`save`、`title`、`message` |

两种风格产生相同的查找键——仅分隔符不同。在项目中选择一种并保持一致。

## 注意事项

- `i18n` 实例的生命周期必须长于所有 `tr()` 调用。通常在 `main()` 开头创建。
- 同一时间只允许一个实例（单例）。创建第二个会抛出 `std::runtime_error`——这是该类唯一可能抛出的异常。其他所有错误情况（缺失键、类型不匹配、文件缺失）均优雅降级，返回原始键。
- 有意不提供返回 `const wchar_t*` 的函数——返回的字符串是临时对象，其指针会悬空。如需 `.c_str()`，请保存 `std::wstring` 结果。
